Why eBay is different

eBay has an official seller API, so it needs no browser at all:

  • listings are created with its Inventory API, keyed by SKU;
  • photos go to eBay Picture Services through its Media API;
  • a listing is removed by withdrawing the offer.

eBay’s user agreement explicitly bars automated agents and bots, so eBay should never go through a browser form. One catch remains: eBay’s push notifications need a public HTTPS endpoint, and ReSellit runs locally, so the design polls orders instead.

Partner APIs worth asking about

Depop has a Selling API for approved partners, and Vinted has Pro Integrations for allowlisted Pro businesses (4–6 week setup). If your account qualifies for either, that marketplace moves from the browser route to the API route. The ReSellit side stays the same, because each marketplace sits behind one adapter.
